# Travel-Advisor-Chat-Bot

This bot uses amadeus API and pyrogram to create a user friendly bot to check the cheapest flight between two destination.

To use this bot first you need to create and develope account on https://developers.amadeus.com/

after creating an account, you need to get the API key from the dashboard

then you need to create bot in telegram and get the API key from botfather of telegram

and you get all the key you can create a .env file and store the key in it.

then run the main.py.

Now you can keep the program running in your local computer or host it in a cloud system so that bot is always on for user.
